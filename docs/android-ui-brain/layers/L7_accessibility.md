# L7 — Accessibility

- Mục tiêu chạm >=48×48 dp cho primary interaction; text scale 1.3–2, không truncate thông tin Rx/giá.
- Icon-only button có contentDescription; ảnh thuần trang trí description null.
- TalkBack thứ tự reading order, đầu đề, errors, actionable labels, trạng thái thời hạn không chỉ dựa màu.
- Keyboard/numeric fields: IME đúng loại, focus và scroll khi bàn phím mở; hỗ trợ Back gesture.
- Contrast kiểm tra cho tất cả cặp màu thực sử dụng; không tuyên bố WCAG PASS khi chưa đo.
